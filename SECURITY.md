# Security Policy

## Reporting a Vulnerability

If you find a security vulnerability in the Security Profiles Operator,
please **do not** open a public GitHub issue.

Instead, please follow the
[Kubernetes security disclosure process](https://kubernetes.io/security/).

The current security contacts for this project are listed in
[SECURITY_CONTACTS](SECURITY_CONTACTS).

You can expect an initial response within 72 hours. The security contacts
will work with you to assess the issue, determine affected versions, and
coordinate a fix and disclosure timeline.
